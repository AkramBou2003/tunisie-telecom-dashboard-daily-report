# Features

## Administrator features

### Employee management
The administrator interface supports CRUD operations:
- Create employee records.
- Read or consult employee records.
- Update employee records.
- Delete employee records.

### Daily CSV import
The administrator uploads a daily report using the application's import action. The application prepares the data and stores the resulting records in the SQL database.

## Data preparation
The recurring preparation operations described for the project include:
- removing unnecessary columns;
- splitting selected columns;
- combining selected columns;
- applying calculations.

Specific formulas, mappings, and company data are not published.

## Employee features
Employees can access dashboards and charts, consult business indicators, and use the visualized information when preparing reports.

## Data visualization
Charts and dashboards were developed using Chart.js and Highcharts.
